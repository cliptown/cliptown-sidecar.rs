# cliptown-sidecar.rs

k8s sidecar for Cliptown.

Inherits [`ores-otel-sidecar`](https://github.com/ores-otel/ores-otel-sidecar.rs).
Bind with `CLIPTOWN_SIDECAR_BIND` (default `127.0.0.1:9090`).

```sh
cargo run --bin cliptown-sidecar
```

Env keys are centralized in `.cli-flags.toml` and generated by `f2e generate` into `generated/{rust,dart,typescript,gleam}`.

Invalid explicit `CLIPTOWN_SIDECAR_BIND` values now fail startup (exit 2) instead of being silently replaced by a default address. This prevents the process from listening on an unexpected interface after a configuration error.
